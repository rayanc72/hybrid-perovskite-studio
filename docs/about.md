# About HPS

Hybrid perovskites combine organic and inorganic building blocks. Their composition,
molecular orientation, and lattice symmetry offer ways to study structure–property
relationships, while their mixed bonding makes conventional molecule-only workflows
awkward. HPS brings structure inspection, molecular transformations, electronic
outputs, and trajectory analysis into one local application.

The Structure workspace distinguishes finite molecular groups from periodic networks
using a geometric bonding model. This supports molecule-specific operations while
retaining the inorganic framework. Other workspaces provide complementary tools for
FHI-aims electronic outputs, molecular dynamics, and general data plotting.

HPS is research software under active development. Its maintained example datasets
have documented provenance and regression values; this does not validate every
material, input convention, or analysis setting. Read the
[scientific scope and limitations](reference/known-limitations.md) before interpreting results.

## Citation and data attribution

Use the software citation metadata in
[CITATION.cff](https://github.com/rayanc72/hybrid-perovskite-studio/blob/main/CITATION.cff)
when citing HPS. Cite the underlying scientific datasets separately, using the
publication references in [Scientific fixture validation](reference/scientific-validation.md)
and the `PROVENANCE.md` included in each example bundle.
